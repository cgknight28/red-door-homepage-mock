# Red Door Homepage Mock

Shareable visual prototypes for Red Door Property Management.

- Open `index.html` to review the homepage mockup. The custom Google reviews section uses local sample review data and is structured so it can later connect to a secure Google Business Profile review feed.
- Open `market-readiness-owner-report.html` to review the responsive owner-facing Market Readiness Report prototype. It includes recommendation filtering, expandable findings, owner decisions, cost summaries, review modal, and print styling.
